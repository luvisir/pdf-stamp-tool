# PDF 合同盖章工具

一个本地运行的 PDF 合同电子盖章小工具。上传合同 PDF 和已经准备好的 PNG 章图后，可以在浏览器里可视化调整普通章、骑缝章的位置与效果，并导出盖章后的 PDF。

## 主要用途

- 给 PDF 合同加盖自己的 PNG 公章。
- 支持普通章和骑缝章，可以单独使用，也可以同时使用。
- 普通章支持按页放置、拖动、旋转、删除当前页公章。
- 骑缝章支持页码范围、距顶部、压入页面、旋转、透明度等设置。
- 普通章和骑缝章都支持模糊度、亮度、饱和度调节，让章图更贴近原 PDF 的扫描质感。
- 支持两种导出模式：
  - 兼容模式：2 倍渲染，文件较小，位置最稳。
  - 清晰模式：4 倍渲染，文字更清晰，文件更大且导出更慢。

> 工具在浏览器本地处理文件，不主动上传合同和章图到服务器。

## 环境要求

- Node.js 18 或更高版本
- npm

## 本地启动

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

默认会监听：

```text
http://127.0.0.1:5173/
```

如果 5173 端口被占用，Vite 会自动换到下一个可用端口，终端里会显示实际访问地址。

## 构建生产版本

```bash
npm run build
```

构建完成后，静态文件会输出到 `dist/` 目录。

本地预览生产构建：

```bash
npm run preview
```

## 运行测试

```bash
npm test
```

## Docker 部署

项目提供了生产环境 Docker 部署方式：先用 Node 构建，再用 Nginx 托管静态文件。

构建镜像：

```bash
docker build -t pdf-stamp-tool .
```

启动容器：

```bash
docker run --rm -p 8080:80 pdf-stamp-tool
```

浏览器访问：

```text
http://127.0.0.1:8080/
```

后台运行：

```bash
docker run -d --name pdf-stamp-tool -p 8080:80 pdf-stamp-tool
```

停止容器：

```bash
docker stop pdf-stamp-tool
```

## Docker Compose 部署

启动：

```bash
docker compose up -d --build
```

访问：

```text
http://127.0.0.1:8080/
```

停止：

```bash
docker compose down
```

## 使用流程

1. 上传合同 PDF。
2. 上传 PNG 章图。
3. 选择普通章、骑缝章，或两者同时选择。
4. 在预览区拖动普通章，或调整骑缝章参数。
5. 根据 PDF 清晰度选择兼容模式或清晰模式。
6. 点击“导出盖章 PDF”下载结果文件。

## 注意事项

- PNG 章图建议使用透明背景。
- 清晰模式会生成更大的 PDF，导出时间也会更长。
- 当前导出方式会把 PDF 页面渲染为图像页，以保证预览和导出位置一致。
- 盖章前建议先用测试合同确认位置和效果。
